# v0.13.0 - Kimi Code and current Agent CLIs

MCO now supports Kimi Code CLI and updates its integrations for the current Antigravity, Pi, OpenCode, Hermes, Codex, and Grok CLIs.

## Highlights

- Added Kimi Code 2.5.2 support, including packaged read-only/write tool profiles, model selection, JSONL answers, and file-backed chain, debate, and synthesis stages.
- Updated OpenCode 2 command arguments and model selection, Hermes context controls, and Antigravity/Grok permission modes.
- Preserved Pi/Hermes model-provider routing across CLI, MCP, and multi-stage runs.
- Corrected false-success handling for Pi errors and truncation, Codex nonzero exits, and Grok headless permission refusals. JSONL answers preserve Unicode line and paragraph separators.

## Compatibility notes

- OpenCode 2 no longer supports the previous plugin-isolation mechanism. Requests for it fail in strict mode or are dropped in best-effort mode.
- A Pi provider override must include a model. Hermes context-file disabling uses `--ignore-rules`, which also disables memory and preloaded skills.
- Read-only debate and synthesis reject providers that cannot enforce a read-only mode. Hermes requires explicit `yolo` execution.
- Kimi profiles restrict tools; they do not create an OS sandbox or disable installed hooks. Kimi uses the shim fallback with `--transport acp`.
- Grok's headless permission-refusal diagnostic marks the invocation as failed, including a run that later recovered with another tool.

## Validation

Antigravity, Pi, Kimi, Codex, and Grok completed real file-read and file-write tasks. Codex→Kimi chain and Kimi debate/synthesis also passed. OpenCode inference was blocked by credentials or exhausted free quota; Hermes was blocked by its configured local model endpoint. Claude Code was excluded from live calls.

The automated suite passed 526 Python tests and 19 Node tests, with three platform-specific skips. Package build/install checks passed. See the [dated compatibility matrix](https://github.com/mco-org/mco/blob/v0.13.0/docs/reference/agent-compatibility-2026-11-07.md) for audited CLI versions and verification limits.

## Install or upgrade

```bash
npm install -g @tt-a1i/mco@0.13.0
mco --version
```

Python 3.10+ is required on PATH. MCO is published through npm only.
